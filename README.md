
# MATLAB Projectile Motion Simulator

## Overview
This project simulates the trajectory of a projectile
using MATLAB.

The program calculates the horizontal and vertical
positions of a projectile launched at a given velocity
and angle.

## Objectives
- Understand projectile motion.
- Practice basic MATLAB programming.
- Generate a trajectory plot.
- Calculate flight time, maximum height, and range.

## Theory

Horizontal position:

x = u * cos(theta) * t

Vertical position:

y = u * sin(theta) * t - 0.5 * g * t^2

Where:
- u = Initial velocity (m/s)
- theta = Launch angle
- t = Time (s)
- g = Gravitational acceleration (m/s^2)

## Parameters
- Initial velocity: 30 m/s
- Launch angle: 45 degrees
- Gravity: 9.81 m/s^2

## Tools Used
- MATLAB
- MATLAB plotting functions

## How to Run
1. Download or clone this repository.
2. Open MATLAB.
3. Open projectile_motion.m.
4. Run the script.
5. View the trajectory plot and calculated results.

## Expected Results
The program displays:
- Projectile trajectory
- Total flight time
- Maximum height
